THE SAM — 3D PERSONAL WEBSITE

Files:
- index.html: website content and structure
- style.css: visual design, responsive layout, 3D CSS effects
- script.js: mobile navigation, pointer tilt and scroll reveals
- assets/the-sam.png: portrait image supplied by the user

HOW TO RUN
1. Extract the ZIP file.
2. Open the folder in Visual Studio Code.
3. Open index.html in a browser, or use the Live Server extension in VS Code.

CUSTOMIZE
- Replace hello@thesam.example in index.html with your real email address.
- Edit the text in index.html to add real projects, socials and contact details.
- This is a front-end website; the contact button opens an email app and is not a backend contact form.
- Google Fonts requires an internet connection. The rest of the website is local.
